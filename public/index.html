📋 Configuração Supabase — criar tabela de backups (primeira vez)
☁️ Execute o SQL abaixo uma única vez no Supabase → SQL Editor. Sem isso os backups ficam apenas no navegador local (limitado). 
CREATE TABLE IF NOT EXISTS backups (
  id           TEXT PRIMARY KEY,
  created_at   TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  tipo         TEXT NOT NULL DEFAULT 'manual',
  usuario_nome TEXT,
  versao       INT DEFAULT 1,
  dados        JSONB NOT NULL
);
ALTER TABLE backups DISABLE ROW LEVEL SECURITY;
